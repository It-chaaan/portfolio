# Personal Portfolio

My personal portfolio website showcasing my projects, skills, experience, and journey as a Computer Science student.

## Status

This portfolio is currently **under development**. I'm building it from the ground up while learning and experimenting with different design and development approaches.

## About the Project

The goal of this portfolio is to create a simple, creative, and personal space where I can showcase:

* My featured projects
* Technical skills
* Education and experience
* Things I'm currently learning
* Ways to connect with me

I'm aiming for a design that feels **clean, friendly, creative, and personal** rather than overly corporate or tech-heavy.
